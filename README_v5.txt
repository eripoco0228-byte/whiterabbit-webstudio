white rabbit WEB STUDIO v5 / GitHub直下配置版

GitHubのリポジトリ直下を、次のようにしてください。

index.html
style.css
script.js
logo.png
DSC04399.jpg

assetsフォルダは不要です。

アップロード方法:
1. ZIPをMacで解凍
2. 上記5ファイルをGitHubのリポジトリ直下にアップロード
3. 既存の index.html / style.css / script.js は置き換え
4. 既存の「WEB STUDIOロゴ.png」は削除して、今回の logo.png を使う
5. DSC04399.jpg は今回同梱のものを使用

画像がすぐ出ない場合:
・GitHub Pagesの反映を1〜3分待つ
・Macで Command + Shift + R で強制再読み込み

後から変更:
・制作サンプルURL: index.html の data-placeholder-link の href="#"
・LINE URL: index.html の id="lineButton" の href="#"
